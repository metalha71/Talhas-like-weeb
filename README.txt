LIKESFF STATIC WEBSITE

No Python, PHP or Node is required. Upload the whole folder to any static hosting:
GitHub Pages, Netlify, Vercel static hosting, Cloudflare Pages, or a normal web server.

Pages:
index.html = Login
register.html = Register
shop.html = Likes
wallet.html = Add Money
orders.html = My Orders
profile.html = Profile
admin.html = Admin

Admin:
Password only: zx
There is no admin username.

IMPORTANT:
This version is a pure HTML/CSS/JavaScript static site. Data is stored in browser localStorage, so it is suitable as a static demo/personal site but it is NOT a secure shared multi-user backend. Admin password and data are visible to users who inspect the JavaScript. For a truly real production website with shared users, secure admin authentication, and balances/orders shared across devices, a backend/database or managed backend such as Supabase/Firebase is required.
